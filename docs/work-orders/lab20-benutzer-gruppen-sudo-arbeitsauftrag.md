# Lab20 – Arbeitsauftrag: Benutzer, Gruppen, sudo und Rechtekonzept

## Ziel

Lab20 baut ein belastbares Verständnis für Linux-Benutzer, Gruppen, sudo-Rechte und betriebliche Rechtekonzepte auf.

Der Fokus liegt auf nachvollziehbarer Rechteprüfung, minimal notwendigen Rechten, sudo-Hygiene und sicherer Dokumentation.

## Leitfragen

- Welcher Benutzer führt einen Befehl aus?
- Welche Gruppenmitgliedschaften wirken?
- Welche sudo-Rechte bestehen?
- Welche Rechte sind für Betrieb wirklich notwendig?
- Welche Rohdaten bleiben privat?
- Welche Bewertung darf öffentlich ins Portfolio?

## Erfolgskriterien

- Rechte-Baseline wurde privat erhoben.
- Öffentliche Bewertung enthält keine unnötigen sensiblen Rohdaten.
- sudo-Rechte sind verstanden und eingeordnet.
- typische Rechtefehler können diagnostiziert werden.
- ein Runbook für Rechteprüfung liegt vor.
- eine Incident-Karte für Rechte-/sudo-Probleme liegt vor.

## Merksatz

Rechte sind kein Bauchgefühl. Rechte sind ein prüfbarer Zustand aus Benutzer, Gruppe, Datei, Prozess und sudo-Regel.
